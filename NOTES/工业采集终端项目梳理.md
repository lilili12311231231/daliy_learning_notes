# 工业数据采集终端项目梳理

> 一个能写进简历、能面试讲清楚的完整项目 = **ADC DMA 多路采集 + Modbus-RTU 从站 + RS485**

---

## 一、为什么要把这两个模块合在一起做（先想清楚）

**单独的 ADC 采样 = 实验报告；合起来 = 项目。**

- 只做「ADC DMA 采集」：老师能看出来这是跟着教程敲的，面试官问三个问题就穿帮。
- 做成「工业采集终端」：ADC 采数据 → 滤波 → 映射到 Modbus 寄存器 → 电脑用 Modbus Poll 通过 RS485 读出来。这就是工控现场一台采集仪最核心的链路，PLC/组态软件(组态王、WinCC)都是这么读数据的。

学长只做第一个模块找不到工作，**不是 ADC 没用，而是他只做了 1/3 就停了**。你要做的不是换一个更难的题，而是把这条链路做完整、做透。

---

## 二、模块 1：ADC DMA 多路采集

### 功能
多通道 ADC 循环采样，DMA 搬运，滑动平均滤波，串口打印采样值。

### 技术要点（面试会问）
| 知识点 | 为什么用 |
|--------|----------|
| DMA 循环模式 | 让硬件自动把 ADC 结果搬进内存数组，CPU 不参与，采样率稳定 |
| 扫描模式 + 连续转换 | 多通道轮流采样，一轮结束自动开始下一轮 |
| 滑动平均滤波 | 去抖、去毛刺，是工控里最简单有效的数字滤波 |
| HAL 库 | `HAL_ADC_Start_DMA(&hadc1, (uint32_t*)buf, len)` 一行启动 |

### 关键步骤
1. CubeMX 配置 ADC1，多通道（如 4 通道）+ DMA2 循环模式 + 扫描模式 + 连续转换。
2. 启动后 DMA 会把结果按通道顺序循环写入数组：`buf[0]=ch1, buf[1]=ch2, ...`。
3. 对每个通道做滑动平均（维护一个窗口数组，取均值）。
4. 串口打印原始值。

### 物理量转换（这一步必须自己写，别用现成）
- 12 位 ADC，参考电压 3.3V：`电压 = 原始值 × 3.3 / 4095`
- 测温度（NTC）：`电压 → 电阻 → 查表/公式 → 温度`
- 测压力/电流（4-20mA）：`电流 = 电压 / 采样电阻`，`物理量 = (电流 - 4mA) / 16mA × 量程`

## 三、模块 2：Modbus-RTU 从站（HAL 裸机）

### 为什么推荐这个而不是 FreeModbus
- FreeModbus 源码复杂、要移植，二本阶段容易被淹没在移植里；这个纯 HAL 手写从站代码量小、注释全，你能看懂每一行——**能看懂每一行，才代表你真正会了**。

### Modbus-RTU 帧结构（背下来）
```
[从站地址(1B)] [功能码(1B)] [数据(N B)] [CRC低字节(1B)] [CRC高字节(1B)]
```
- 帧与帧之间间隔 ≥ 3.5 个字符时间（用于判断一帧结束）。

### 支持的三个功能码
| 功能码 | 含义 | 用途 |
|--------|------|------|
| 0x03 | 读保持寄存器 | 主机读你采集到的数据 |
| 0x06 | 写单个寄存器 | 主机改单个参数 |
| 0x10 (16) | 写多个寄存器 | 主机批量写参数 |

### 两个必须搞懂的硬知识点
1. **CRC16 校验**：多项式 0xA001，初值 0xFFFF。背不住没关系，但要能说清楚「为什么要有校验」（RS485 现场干扰大，靠 CRC 保证帧没传错）。
2. **RS485 与 RS232 的区别**：RS485 是差分信号、半双工（MAX485 的 DE/RE 引脚控制收发方向，收发要切换）、可挂多个从站、传输距离远；RS232 是单端、全双工、点对点。

### 掉电保存
- 从站地址等参数写入片内 Flash：解锁 → 擦除页 → `HAL_FLASH_Program` → 上锁。

## 四、合体流程（端到端）

```
ADC 采样 → 滑动平均滤波 → 物理量转换 → 赋值给 Modbus 保持寄存器
          → USART + MAX485(RS485) → 电脑 Modbus Poll 读取
```

### 寄存器映射表（示例，写进你的 README）
| 寄存器地址 | 内容 | 说明 |
|-----------|------|------|
| 0x0000 | 通道1 电压(×100) | 如 330 = 3.30V |
| 0x0001 | 通道2 温度(×10) | 如 265 = 26.5℃ |
| 0x0002 | 通道3 压力 | |
| 0x0003 | 通道4 电流(×100) | |
| 0x0100 | 从站地址 | 掉电保存，默认 0x01 |

## 五、做到什么程度算「完成」（验收标准）

- [ ] Modbus Poll 能读到你采集的实时数据（功能码 03）
- [ ] 能写参数（功能码 06/16），且从站地址掉电后不丢
- [ ] 接一个**真实传感器**（NTC 温度 / 4-20mA 电流），不是只接电位器
- [ ] 写一份 README：接线图 + 寄存器表 + 运行截图
- [ ] 录一段 30~60 秒演示视频
- [ ] 能口头回答：为什么用 DMA？滑动平均怎么写的？CRC 怎么算？03 和 06 区别？RS485 和 RS232 区别？

## 六、进阶方向（做完上面的再选，别贪多）

1. **CAN 采集节点**（推荐）：你已学过 CAN，把 ADC 数据通过 CAN 发出去，车载/工业方向很吃香。
2. **Modbus TCP**：加 W5500 以太网模块，覆盖物联网/远程采集方向。
3. **画采集终端 PCB 板**：软硬件闭环，最加分——因为你会画 PCB。
